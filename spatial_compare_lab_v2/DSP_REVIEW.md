# DSP model review — 2026-09-05

Room parameters were subsequently revised for the Don't Start Now render. See [ROOM_PARAMETER_REVIEW.md](ROOM_PARAMETER_REVIEW.md) for current distance gains and Eyring decay estimation; earlier descriptions below document the initial v2 settings.

## Assessment

Keep the hybrid architecture: two virtual loudspeakers, measured HRIRs for the direct sound, image-source early reflections, and a compact FDN late field. It suits a desktop baker feeding a small embedded renderer. The current project is a useful listening prototype, but its settings are not calibrated room measurements. v2 fixes concrete comparison and stereo-reverb issues without replacing the established HRTFs or retuning the presets.

This review describes the working files on disk, including existing uncommitted edits. The original README is stale: the code has six presets, 3-D reflection geometry including floor/ceiling, 1–10 selected reflections, distance controls, Sabine-derived decay, and separate high-frequency feedback. It is no longer only a horizontal six-reflection room with fixed 55 ms late predelay.

## Distance, angle and room limitations

- Direct amplitude is clamp(1/d, 0.08, 1.75). ER already contains 1/path spreading but is additionally multiplied by clamp(1/sqrt(d), 0.20, 1.35). Late send grows as clamp(0.55+0.45*sqrt(d), 0.55, 2). This is artistic distance enhancement, not a fully consistent physical propagation model. Keep these settings for continuity; a future physical mode should use actual 3-D source distance, remove the extra ER distance factor, and calibrate diffuse-field energy separately.
- `speaker_distance_m` is horizontal radius; speaker height can differ (Theater). Direct gain uses horizontal radius while reflected delay subtracts 3-D direct distance. v2 checks horizontal bounds but does not claim to resolve that modeling mismatch.
- Direct HRIR has its recorded timing; no extra d/343 direct propagation delay is added. ER delays are relative excess path times, rounded to integer samples (at 48 kHz, 20.83 microseconds/sample). Keeping direct sound as the time origin is useful for this static comparison, but absolute travel time cannot be inferred. Fractional delay baking is worth testing for sensitive comb-filter/ITD comparisons.
- 0 degrees is front; positive is right; index = round(wrapped_angle/5) modulo 72. -30/+30 maps to 66/6. These are this dataset's conventions, not universal SOFA conventions.
- Floor and ceiling events have correct 3-D path lengths but no elevation-dependent ear filtering. This can color sound without providing the corresponding elevated localization cues. Full-sphere measured HRIR lookup is a meaningful next step; the existing SOFA converter reduces the dataset to a horizontal ring, so that branch alone does not solve it.
- Material constants are hand-picked three-band values, not measured finishes. Scattering reduces specular amplitude without conserving the removed energy in a calibrated diffuse field. Sabine assumes a diffuse field and is only approximate for strongly absorbing/small rooms; compare Eyring estimates and measured decay before assigning physical room labels.
- Strongest-N selection is by mid-band amplitude, with minimum gain/delay thresholds. Events can appear/disappear abruptly during parameter sweeps; this renderer is static. A moving renderer needs smooth changes and a more explicit ER/diffuse transition.
- `shape_ir_3band` multiplies a real frequency magnitude then truncates the inverse FFT back to the HRIR length. That is zero-phase circular shaping with discarded support, not a causal material filter. A causal shelf/minimum-phase material response with sufficient retained tail is a high-value future bake experiment.
- The FDN's first possible output occurs after predelay PLUS its shortest delay (29.7 ms), not at the printed predelay. Compare this onset to the last selected ER when tuning the transition. Nominal RT60 is not an independently measured decay result.
- Default 48 kHz WAV tags cannot establish the source MAT's true recording rate. Verify provenance. A rate mismatch changes both spectrum and time cues; merely relabeling a file is not resampling.

## Research-backed candidates, and why they are deferred

These are promising experiments, not claims of improved listening in this repository.

1. **Time-aligned, magnitude-corrected HRTF interpolation.** Arend et al. (2023) report reduced magnitude interpolation error on simulated HUTUBS sets, especially for sparse grids. This supports an offline interpolated-profile experiment, not naive sample-by-sample blending of differently delayed HRIRs. Preserve measured grid points, explicitly handle ear delays, and validate withheld directions before adopting it. At fixed +/-30 degrees the present profile already has grid points, so this is not needed for the baseline. Source: https://arxiv.org/abs/2303.09966
2. **Offline optimization of a small FDN.** Dal Santo et al. (DAFx 2023) optimize parameters to reduce coloration and control response sparsity, including small networks. This fits the baker/runtime split: learn coefficients offline, ship a compact DSP network. First measure this implementation's impulse-response spectrum, echo density and band decay; do not add runtime ML. Source: https://www.dafx.de/paper-archive/2023/DAFx23_paper_32.pdf
3. **Full-direction SOFA data and explicit metadata.** SOFA SimpleFreeFieldHRIR carries measurement positions, sampling rate and delay information. Use those native directions rather than assuming all imported profiles are exact 5-degree measurements. Validate receiver ordering, coordinate conversion and delays. The sibling SOFA project is useful groundwork, but its README describes nearest-neighbor horizontal reduction. Source: https://www.sofacoustics.org/mediawiki/index.php/SimpleFreeFieldHRIR
4. **Measured early response plus parametric late reverb.** This hybrid family is established rather than a new replacement: the 2014 hybrid processor combines early convolution and an FDN tail. A measured BRIR is a useful calibration target for this project's synthetic rooms. Source: https://www.dafx.de/paper-archive/details.php?id=ar34-t6tsn7TfoIpzLzu7Q

Other engineering experiments inferred from this code: head-relative direction updates with tracked head rotation and crossfaded filters for a future interactive renderer; source-distance-dependent HRTFs if near-field use is required; causal material shaping; bandwise RT60/DRR and interaural cross-correlation reports; input-FFT sharing/partitioned convolution. These require extra data, hardware or validation and are not implemented in v2. Neural personalization cannot be justified from this horizontal dataset and code review alone.

## What v2 establishes

It gives a more reliable static comparison tool, not a newly validated spatial-hearing model. The measured direct HRIRs, preset distances/materials, adaptation and heuristic distance law remain the reference. Six automated tests check concrete numerical behavior; end-to-end impulse rendering checks completion, tails and finite output. No headphone listening study, embedded timing benchmark, individual localization test or measured-room fit has been performed.
